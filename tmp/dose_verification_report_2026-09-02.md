# Сверка доз нозологий с источником КР (прочерк=проверка, НЕ врачебное одобрение)

Харнесс: `src/pipeline/extraction/dose_verification.py` сверяет дозу из БД (db/antibio_db.json)
с извлечённой из официального PDF КР дозой (DOSA KB: source_quote + page + pdf_sha256).
**Это машиная сверка-доказательство, не медицинский вердикт.** P5.6/P6 — за владельцем/врачом.

## Про расхождения (113 проверок)
Корневая причина почти всех — **не гранулярность данных, а формат**:
- БД хранит **суточную дозу** (dose_mg_day_fixed), КР-текст часто пишет **разовую**.
  Пример: клиндамицин 1200 (сут) vs КР «300 мг» (разовая×4); доксициклин 200 (сут) vs «100 мг»;
  ципрофлоксацин 400 (сут) vs «400 мг»; левофлоксацин 500 (сут) vs «500 мг».
- Часть — выбор др. правильного варианта из диапазона (напр. амоксициллин 1750 vs «1 г» —
  875×2 — корректный предел 500-1000).
- Немного реальных — единичные cefixime/цефтриаксон в одном из вариантов.

Это не «ошибки доз», а неоднозначность представления (сут/разовая) + выбранные альтернативные
варианты из разрешённого диапазона. Для полной гарантии нужен разбор каждого из 38 врачом.
