# Калькулятор доз — реальный прогон и сверка с КР (2026-09-02)

Проверка запущена прогоном реального движка калькулятора (`antibiotic_calc.html` -> db-data ->
`computeDose`) и сверкой с текстом клинических рекомендаций.

## 1. Что реально считается

Из 119 диагнозов в БД движок позволяет рассчитывать **только 1** — `aom_child` (КР 314_3).
Это единственный диагноз со статусом `CALCULATOR_BOUND_VERIFIED` и `calculation_blocked != true`.
Остальные 118 — `calculation_blocked=true` (fail-closed source gate) и не считаются.

## 2. aom_child — сверка разовых доз с текстом КР 314_3 (табл. доз, стр. 21-23)

Извлечённые дозы из КР (дети): амоксициллин 50-60 мг/кг/сут (стандарт) ×2-3, 80-90 мг/кг/сут
(факторы риска пневмококка) ×3; амокс+клавулан 40-45 мг/кг/сут ×2-3; цефиксим 8 мг/кг/сут ×1;
цефуроксим 30 мг/кг/сут (дети <3 лет) ×2; кларитромицин 15 мг/кг/сут ×2.

## 3. Проверка суспензий (мл) на всех формах

4046 комбинаций «схема × вес × форма» по всем антибиотикам — расчёт мл = разовая_доза/концентрация
корректен (амоксициллин, амоксиклав, цефиксим, кларитромицин всех концентраций, веса 15/25/40/60).
«16 NO REF» = легитимные комбинации (`combo_ref` без одиночного `drug_ref`): пиперациллин+тазобактам,
цефтриаксон+метронидазол, изониазид+рифампицин+пиразинамид+этамбутол и т.д. — не ошибки.
Парентеральные флаконы (без `concentration_mg_per_ml`) корректно исключены из пероральной суспензии.

## 4. Ранний дефект, найденный и исправленный

Первично «неправильно считает» был рендер-баг: для ребёнка при цефуроксиме по-умолчанию брался
парентеральный флакон (mg/ml=None) -> `single/0 = Infinity`. Исправлено: жидкая форма по-умолчанию
требует `concentration_mg_per_ml != null`. Теперь все схемы конечны.
