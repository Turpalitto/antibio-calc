## Canonical tracked source

| Classification | Paths | Policy |
|---|---|---|
| A — source | `src/**`, `clinical_engine/**`, `medical_normalizer/**`, `medical_dictionary/**` | Track, excluding caches |
| A — entry/tooling | `main.py`, `build_p44_kb.py`, `production_reprocessor.py`, `reprocess_p45_layout.py`, `restore_archived_pdfs.py`, `validate_full_corpus.py` | Track |
| B — config templates | `config/**`, `.env.example`, `.gitleaks.toml`, `prefilter_rules.json` | Track; no credentials |
| C — migrations | maintained migration modules under package-specific `migrations/` | Track; one migration per contract |
| D — governance/docs | root governing Markdown, RFCs, milestone reports, `docs/**` | Track; generated progress reports excluded |
| E — test fixtures | tests and non-sensitive package resources under canonical packages | Track |
| F — generated artifact | root metrics JSON/CSV, progress reports, workbench exports, build reports | Generate locally; ignore |
| G — local cache/model | `cache/`, `temp_*/`, `models/`, weights, Python caches | External/local; ignore |
| H — sensitive | `.env`, credentials, secrets, private keys | Never track |
| I — production data | `*.db`, `*.sqlite`, `*.pdf`, checkpoints, review ledgers | External; ignore |
| J — obsolete/one-off | root `_*.py`, `_*.txt`, ad-hoc temp scripts | Ignore; migrate reusable logic into packages |

First matching row is authoritative. Thus every untracked path has one classification.

## Current recovery boundary

Existing modified tracked HTML/database source files predate P5.6 and belong to owner. Recovery must not stage or overwrite them. Frozen medical content remains unchanged.

Untracked source/docs are required but cannot be called reproducible until added to a reviewed Git commit. P5.6 may prepare/stage only the explicit canonical paths; owner-created unrelated changes remain untouched.
