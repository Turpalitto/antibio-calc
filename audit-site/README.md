# audit-site — архивный дашборд внешнего аудита (снимок 2026-09-29)

Одностраничный React/Vite-дашборд с результатами **внешнего аудита репозитория
на коммит `0cf8e33` (2026-09-29)**. Все данные захардкожены в
`src/data/audit.ts` и **не обновляются автоматически** — цифры там
(«55.1 % REJECT», «119/120 заблокировано», «1 373 теста») описывают состояние
на тот момент и уже не соответствуют текущему репозиторию. Актуальное
состояние — `PROJECT_STATE.md`, `docs/audits/AUDIT_2026-10-14*.md`.

Дашборд не участвует ни в сборке калькулятора, ни в тестах, ни в CI; это
исторический артефакт, оставленный как есть (F-3 аудита 2026-10-14). Если он
перестанет быть нужен — каталог можно удалить целиком, на остальной проект это
не влияет.

## Сборка

```bash
cd audit-site
npm ci
npm run build        # → dist/index.html (единственный файл, inline JS/CSS)
npm run dev          # локальный dev-сервер Vite
```

`dist/` в `.gitignore` — собранный файл не коммитится.

## Зависимости и безопасность

Зависимости только build-time (React 19, Vite 7, Tailwind 4,
`vite-plugin-singlefile`). `npm audit` после обновления 2026-10-14
(vite 7.3.7, esbuild, source-map-js): остаются 3 «high» —
`braces` ≤ 3.0.3 (GHSA-vfj7-8cjw-p6xm, стек-исчерпание на глубоко вложенных
glob-шаблонах) через `micromatch` ← `vite-plugin-singlefile`. Исправленного
релиза `braces` не существует (3.0.3 — последний), а предлагаемый npm «fix» —
откат плагина до 0.9.0. Шаблоны glob здесь задаёт только сам конфиг сборки,
внешний ввод в них не попадает, поэтому риск принят; перепроверять при
обновлении зависимостей (`npm audit`).
