# docs/history — архив исторических отчётов (G-1, 2026-10-14)

Сюда перенесены **199 файлов из корня репозитория**: отчёты, RCA, базлайны, аудиты и
одноразовые артефакты прогонов, на которые **не ссылается ни код, ни тесты, ни
конфигурация, ни действующие документы** (`README.md`, `AGENTS.md`,
`GOVERNANCE_SOURCE_OF_TRUTH.md`, `HANDOFF.md`, `ROADMAP_STATUS.md`, `CHANGELOG_DB.md`).
Правило отбора: имя файла описывает отчёт/аудит/базлайн/сессию (REPORT, RCA, AUDIT,
BASELINE, ANALYSIS, VERIFICATION, SUMMARY, RC03x …), но не политику/спецификацию/RFC/
контракт/реестр — те остались в корне. Содержимое файлов не менялось; относительные
markdown-ссылки переписаны так, что ни одна не сломалась (проверено до/после:
4 битые ссылки существовали и до переноса, новых нет). История `git log --follow` сохранена.

Это **архив**: цифры и статусы внутри описывают состояние проекта на дату документа и
не являются актуальными. Актуальное состояние — `PROJECT_STATE.md`, очередь задач —
`NEXT_TASK.md`, решения — `DECISIONS.md`, журнал — `AI_LOG.md`.
